# Security

## What the plugin does

ASCII Worlds runs inside Hermes Desktop with the app's normal plugin permissions. It draws
on a canvas and stores its settings in the plugin's own local storage. It makes no network
requests, runs no shell commands, reads no files and never reads conversation text.
Its source is a single readable file.

## Reporting a vulnerability

Please report security problems privately through GitHub:
**Security -> Report a vulnerability** on the
[repository page](https://github.com/dudicslevente/hermes-ascii-worlds/security/advisories/new).
Do not open a public issue for a vulnerability. You will get a reply as soon as possible,
and a fix will be released before details are published.

## Supported versions

Security fixes go into the latest release.
