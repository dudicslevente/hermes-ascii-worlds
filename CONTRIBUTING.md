# Contributing

Thanks for taking a look. New designs, bug fixes, docs and testing on other systems are all welcome, and small, focused changes are the easiest to review. If you plan something bigger, such as a new habitat, open an issue first so we can talk it through and avoid overlap.

## Set up

You need Node 20 or newer. There are no runtime dependencies.

```sh
npm run build    # bundle src/ into desktop/plugin.js and demo.html
npm run verify   # build, syntax-check the bundle, run the unit tests
```

The browser, timing and motion-capture checks in `tests/` also need Playwright and a Chromium build, which are not part of this repository. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) has the exact steps, including `scripts/prepare-harness.mjs`.

## Ground rules

- The plugin is one plain ES module with no JSX. It may import only `react`, `react/jsx-runtime` and `@hermes/plugin-sdk`. `scripts/build.mjs` enforces the single-file shape and the tests check the import set.
- No network access, no telemetry, no secrets.
- Do not edit `desktop/plugin.js` or `demo.html` by hand; they are generated by `npm run build` and must be committed.
- Everything the Background mode adds to the page must be removed again on turn-off, unmount and dispose. Add a test with any new side effect.
- Never hard-code chrome colours in the settings page; use the app's theme variables. Colours inside the canvas art are fine.
- Keep source, comments and UI text plain and human. No emojis.
- Keep every claim honest: if something was only checked against a mock page, say so.

- Code that restyles Hermes Desktop's own markup (only the Chat area placement does) must stay between the `@chat-area:begin` and `@chat-area:end` markers, so the catalog build can leave it out. New features should not need it. `npm run build:catalog` and `tests/catalog-variant.test.mjs` check this.

## Adding a habitat

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). In short: add a drawing function to `src/art.js`, register the scene in `src/settings.js`, and add a deterministic render test and a motion check so the creatures actually travel.

## Reporting bugs

Include your Hermes Desktop version, your operating system, the placement you use, and the text from **Check background** in the plugin's settings page.
